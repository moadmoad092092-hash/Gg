الهروب من النظام — نموذج لعبة 3D للويب
========================================

طريقة التشغيل:
1) فك ضغط ملف ZIP.
2) افتح index.html في متصفح حديث يدعم WebGL و JavaScript modules.
3) يلزم اتصال بالإنترنت لتحميل Three.js من CDN.
4) على الهاتف، استخدم عصا الحركة أسفل اليسار، وأزرار القفز والجري والتسلل أسفل اليمين.

التحكم على الكمبيوتر:
- WASD أو الأسهم: حركة
- Space: قفز
- Shift غير مطلوب؛ زر الجري مخصص للهاتف
- Escape: إيقاف مؤقت

الهدف:
- اجمع 5 نوى بيانات خضراء.
- تجنب كاميرات المراقبة الحمراء، ويمكن للتسلل مساعدتك.
- اذهب إلى البوابة الخضراء في نهاية المنشأة بعد جمع كل النوى.

ملاحظات:
- هذا نموذج أولي قابل للعب برسوم ثلاثية الأبعاد، وليس APK ولا مشروع Roblox.
- إذا فتح index.html مباشرة ولم يعمل بسبب قيود المتصفح، استضف المجلد مجانًا على GitHub Pages أو Netlify، أو استخدم محرر ويب يدعم HTML/CSS/JS من الهاتف.
- لا توجد مفاتيح API ولا اشتراكات مطلوبة؛ محرك Three.js يُحمّل من CDN عبر الإنترنت.
